CONTEXTO DO PROJETO
────────────────────────────────────────────────────────────────────────────────

Estou desenvolvendo uma plataforma de PROSPECÇÃO TECNOLÓGICA INTELIGENTE que
busca e analisa patentes, artigos científicos e notícias usando IA.

A plataforma guia o usuário através de um fluxo de 7 etapas com decisões
(gateways) onde o usuário pode refinar resultados iterativamente.

OBJETIVO: Design clean, intuitivo e que visualize bem o fluxo de dados
passando pelas etapas.

────────────────────────────────────────────────────────────────────────────────
FLUXO DE DADOS - 7 ETAPAS
────────────────────────────────────────────────────────────────────────────────

1. PARÂMETROS INICIAIS
   ├─ Gateway: "Gerar com IA?"
   └─ Output: SearchParams (tema, keywords, fontes, datas)

2. ESPECIFICAÇÃO
   ├─ Gateway: "Especificar? / Usar anterior? / Gerar novo?"
   └─ Output: SearchParams refinados

3. BUSCA INICIAL
   ├─ Armazena parâmetros
   ├─ Executa busca
   └─ Output: SearchResult[] (100+ resultados)

4. REFINAMENTO DE QUERY ⚠️ LOOP AQUI
   ├─ Gateway: "Satisfeito?"
   ├─ SIM → Próxima etapa
   └─ NÃO → Loop: Sugere termos → Cria query → Busca novamente

5. BUSCA FINAL
   ├─ Busca com query refinada
   └─ Output: FinalSearchResponse + Gera Charts automaticamente

6. VALIDAÇÃO DE GRÁFICOS
   ├─ Gateway: "Satisfeito com gráficos?"
   ├─ SIM → Gera relatório
   └─ NÃO → DELETE gráfico, volta regenerar

7. RELATÓRIO & DOWNLOAD
   ├─ Sintetiza dados
   ├─ Gera PDF/XLSX/DOCX
   └─ Output: File download link

────────────────────────────────────────────────────────────────────────────────
DADOS PASSANDO PELO SISTEMA
────────────────────────────────────────────────────────────────────────────────

SearchParams:
  • theme: string (ex: "Machine Learning")
  • keywords: string[] (ex: ["IA", "Healthcare"])
  • yearStart: number (ex: 2020)
  • yearEnd: number (ex: 2026)
  • sources: {patents: bool, articles: bool, news: bool}

SearchResult[] (Resultados da busca):
  • 50-200 itens por etapa
  • Cada item: id, title, source (patents/articles/news), year, abstract, relevance%

RefinedQuery (Query refinada):
  • Original query (CQL)
  • Refined query (CQL com termos selecionados)
  • selectedTerms: string[]
  • removedTerms: string[]

Chart[] (4 tipos):
  • Line (timeline)
  • Bar (by source: patents, articles, news)
  • Pie (distribution)
  • Scatter (year vs relevance)

ReportData (Resultado final):
  • searchParams (originais)
  • initialResults[] (primeiros 50)
  • finalResults[] (finais, refinados)
  • charts[] (3-5 gráficos)
  • summary: string (texto sintetizado)
  • statistics: {totalPatents, totalArticles, totalResults, timeline}
  • downloadUrl, fileName
