1. VISÃO GERAL
================================================================================

A interface web permite que usuários finais interajam com o sistema de
prospecção tecnológica através de um navegador, sem necessidade de conhecimento
técnico.

COMPONENTES PRINCIPAIS:
1. ✓ Pesquisa (tema, período)
2. ✓ Acompanhamento de progresso em tempo real
3. ✓ Editor de Markdown/LaTeX no navegador (tipo Overleaf)
4. ✓ Preview side-by-side
5. ✓ Export para PDF
6. ✓ Histórico de pesquisas

================================================================================
2. ARQUITETURA
================================================================================

Frontend:
├─ React.js ou Vue.js (framework)
├─ Monaco Editor (editor de texto)
├─ Markdown-it + KaTeX (preview)
├─ Tailwind ou Material-UI (styling)
└─ Socket.io (WebSocket)

Backend (já implementado):
├─ FastAPI (API REST)
├─ Ollama (LLM local)
├─ ChromaDB (RAG)
└─ PostgreSQL (database)

Integração:
├─ HTTP REST para requisições
├─ WebSocket para progresso em tempo real
└─ Local Storage para rascunhos

4. COMPONENTES PRINCIPAIS
================================================================================

4.1 SearchForm Component
└─ Entrada de tema (texto)
└─ Seletor de período (slider ou input)
└─ Botão submit
└─ Validação client-side
└─ Feedback visual de validação

4.2 ProgressTracker Component
└─ Barra de progresso (0-100%)
└─ Informações por fase
└─ Métricas em tempo real
└─ Tempo decorrido
└─ Status (em andamento / concluído)
└─ Atualiza via WebSocket (não precisa refresh)

4.3 ReportEditor Component
└─ Monaco Editor (VSCode embed)
└─ Sintaxe highlighting (Markdown/LaTeX)
└─ Auto-completion
└─ Line numbers
└─ Auto-save (a cada 30s em Local Storage)
└─ Undo/redo (Ctrl+Z/Ctrl+Y)
└─ Search and replace (Ctrl+H)
└─ Shortcuts:
   - Ctrl+B → **bold**
   - Ctrl+I → *itálico*
   - Ctrl+` → code
   - Tab → indent
   - Shift+Tab → unindent

4.4 PreviewPanel Component
└─ Renderização de Markdown
└─ Compilação de equações (KaTeX)
└─ Scroll sincronizado com editor
└─ Atualiza em tempo real conforme digita
└─ Modo full-screen
└─ Zoom in/out

4.5 ExportButton Component
└─ Download PDF (via pandoc ou wkhtmltopdf)
└─ Download LaTeX (.tex)
└─ Download Markdown (.md)
└─ Email (com PDF anexado)
└─ Link compartilhável (gera UUID no BD)

4.6 HistoryComponent
└─ Lista de pesquisas anteriores
└─ Thumbnail do resultado
└─ Data e hora
└─ Duração
└─ Clique para abrir
└─ Opção para duplicar
└─ Opção para deletar

================================================================================
5. EDITOR DE MARKDOWN/LATEX NO NAVEGADOR
================================================================================

CARACTERÍSTICAS:

1. Edição em Tempo Real
   - Usuário digita no editor
   - Preview atualiza imediatamente
   - Sem delay perceptível
   - Auto-save a cada 30 segundos

2. Sintaxe Highlighting
   - Markdown: headings, bold, italic, lists, código
   - LaTeX: commands, environments, math mode
   - Temas: light, dark, solarized

3. Auto-Completion
   - \begin{} autocompleta com \end{}
   - # autocompleta com espaço
   - Sugestões de comandos LaTeX
   - Snippets customizados

4. Preview Side-by-Side
   - Esquerda: editor
   - Direita: preview renderizado
   - Sincronização de scroll
   - Modo full-screen para editor ou preview
   - Toggle preview/editor para mobile

5. Histórico de Versões
   - Salva último backup a cada 30s
   - Mantém últimas 10 versões
   - Botão "Revert to version"
   - Mostra timestamp de cada versão

6. Validação
   - Detecta LaTeX syntax errors
   - Aviso se há seções incompletas
   - Valida estrutura REPTEC/AGITEC
   - Oferece sugestões de correção

EXEMPLO DE USO:

1. Relatório é gerado em Markdown
2. Frontend exibe em editor com preview
3. Usuário pode:
   - Editar texto diretamente
   - Mudar formatação (bold, itálico, etc)
   - Adicionar/remover seções
   - Ajustar equações LaTeX

4. Ao clicar "Download PDF":
   - Sistema converte Markdown → LaTeX
   - Compila LaTeX → PDF
   - Retorna PDF pronto

5. Usuário pode:
   - Fazer novos downloads após edições
   - Enviar por email
   - Compartilhar link público
   - Exportar em vários formatos

6. INTEGRAÇÃO COM BACKEND
================================================================================

ENDPOINTS EXISTENTES (já implementados):
POST /api/v1/chat/refine-topic
POST /api/v1/chat/probe/search
POST /api/v1/chat/extract-terms
POST /api/v1/chat/final/search
POST /api/v1/reports/generate

NOVOS ENDPOINTS NECESSÁRIOS:
POST /api/v1/reports/export-pdf
  Input: {markdown: "...", format: "latex"|"html"}
  Output: PDF binary

POST /api/v1/reports/export-latex
  Input: {markdown: "..."}
  Output: LaTeX file text

GET /api/v1/research/history
  Output: [{id, title, created_at, duration}, ...]

GET /api/v1/research/{id}
  Output: {id, title, description, report_markdown, ...}

DELETE /api/v1/research/{id}
  Output: {success: true}

WEBSOCKET:
WS /api/v1/ws/search-progress
  Retorna updates em tempo real:
  {
    "phase": "probe_search",
    "progress": 65,
    "patents_found": 1523,
    "articles_found": 245,
    "elapsed_seconds": 12.5,
    "estimated_remaining": 5
  }

8. FLUXO DE DADOS DETALHADO
================================================================================

USER DIGITA TEMA
     ↓
FRONTEND valida entrada
     ↓
FRONTEND POST /api/v1/chat/refine-topic
     ↓
BACKEND processa (2-5s)
     ↓
BACKEND retorna tema refinado
     ↓
FRONTEND abre WebSocket: WS /api/v1/ws/search-progress
     ↓
FRONTEND POST /api/v1/chat/probe/search
BACKEND começa fase 1, envia updates via WebSocket
     ↓
FRONTEND recebe WebSocket updates
     ↓
ProgressTracker atualiza em tempo real (sem refresh)
     ↓
Fases 2, 3, 4 prosseguem (com updates WebSocket)
     ↓
BACKEND completa busca, inicia geração
     ↓
BACKEND POST /api/v1/reports/generate
     ↓
BACKEND gera Markdown via RAG + Ollama
     ↓
BACKEND retorna Markdown formatado
     ↓
FRONTEND recebe Markdown
     ↓
FRONTEND exibe em ReportEditor
     ↓
PreviewPanel renderiza preview imediatamente
     ↓
USUÁRIO pode:
├─ Editar (Monaco Editor)
├─ Ver preview em tempo real
├─ Auto-save cada 30s
├─ Undo/redo
├─ Search and replace
└─ Quando pronto:
   └─ Clica "Download PDF"
      └─ Markdown é convertido em LaTeX
      └─ LaTeX é compilado em PDF
      └─ PDF é retornado para download

9. AUTENTICAÇÃO E SEGURANÇA
================================================================================

Login (futuro):
- JWT tokens para autenticação
- Email + password
- OAuth (Google, GitHub)
- Session management

Autorização:
- Usuários só veem suas pesquisas
- API valida ownership antes de retornar dados
- DELETE apenas para próprias pesquisas

Segurança:
- HTTPS obrigatório em produção
- CSRF protection
- Rate limiting por IP
- Input validation no frontend
- SQL injection prevention (ORM)
- XSS protection (Markdown-it safe mode)

Privacidade:
- Opção de pesquisas privadas vs públicas
- Link compartilhável com token único
- Dados sensíveis não são logados
- Relatórios podem ser deletados
